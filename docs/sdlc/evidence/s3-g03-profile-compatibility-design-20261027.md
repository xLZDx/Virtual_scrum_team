### Fail-closed toolchain contract

Before any separately authorized build, the operator-approved boundary must already contain the exact Go archive and the complete server module closure. The build process must not contact `go.dev`, a module proxy, checksum database, telemetry exporter, or any other external service. It must use the pinned server commit, `GOTOOLCHAIN=local`, `GOPROXY=off`, `GOSUMDB=off`, and verified `go.sum` module checksums from the local cache. The build manifest records toolchain identity, archive digest, module list/sums, target, environment, flags, native toolchain inputs (including whether cgo is required), effective configuration, and output digest. A missing input, implicit download/switch, unresolved native input, or digest mismatch stops the build before candidate execution and leaves the result non-approving. No such build is authorized or performed by this design record.

The official Go release history lists Go 1.26.10 as released on 2026-10-19 and describes security fixes in that patch. The official download index lists the Linux x86-64 archive and checksum above. This records upstream-published metadata only; independent archive verification and toolchain installation remain future gated actions.
