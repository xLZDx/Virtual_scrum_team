## Change

`tools/vst/preflight_host_capture.py` keeps the production identity check strict by default and adds an internal bounded waiter for one exact transition: all-root UID/GID arrays to the configured worker UID/GID arrays, for the same PID and start time, exact probe cgroup, active systemd invocation, boot ID, and systemd generation. The wait uses one five-second monotonic deadline; each nested systemd subprocess receives only the remaining time, and sleep is capped to that same deadline. Any other credential values, identity drift, invocation/systemd change, or unsettled transition fails closed. Namespace isolation and subsequent process identity checks are unchanged.

The consumed tuple above is added to the permanent retired-identity set. The focused regression asserts it is refused before durable marker creation. The bundle regression checks the candidate identities against all three consumed identities.
