# Change record 0016: S1 review remediation B (store, runner, slice)

## What changed
- `tools/vst/store.py` (rewritten): schema version 2 (`PRAGMA user_version`, refusal on mismatch or legacy tables), `recursive_triggers` ON, `chmod 0o600` best effort, bounds-checked integers, explicit COMMIT/ROLLBACK in `_tx` with a distinct `StoreBusyError`. New `tasks` table and `register_task`/`get_manifest` (story/task link and `manifest_sha256` stored once, append-only). Lease history: `leases` rows are never overwritten or deleted (triggers), status LIVE/RELEASED/EXPIRED/FENCED, `wrote` and `marked` flags, one LIVE lease per task, consecutive attempts; slots now point at `lease_id`. `retry_cap` is enforced at `acquire_lease` and commits a signed `RETRY_EXHAUSTED` marker before raising `kind='retry'`. `append_receipt(receipt, story_id, key)` verifies signature, manifest hash, task/story link, declared slot, derived result, epoch, terminal markers, live lease holder/epoch/expiry, retry bound and chain position. Supervisor isolation: `SUPERVISOR_SLOT` receipts only through `append_supervisor_receipt(..., supervisor_key=)` and the supervisor methods, verified with the supervisor key. `supervisor_reap_and_mark(supervisor_key, runner_id)` writes `WORKER_LOST` only for leases with `wrote = 0`; `mark_budget_exceeded(task_id, supervisor_key, runner_id)` is idempotent. Phase API `set_phase`/`get_phase` (epoch compare-and-swap). Event log is an HMAC chain keyed with the new constructor argument `event_key` plus a keyed anchor row, so edit, deletion and truncation are detected; closed enums `EVENT_KINDS`, `LEASE_STATUSES`, `STORY_STATES`.
- `tools/vst/runner.py` (rewritten): `run_and_sign` takes the whole `manifest`; receipts carry `manifest_sha256`; every argv must equal an `allowed_commands` entry of the slot and `expected_test_ids` must equal the manifest required tests (refused before running); per-stream output cap with fail-closed exit code -3; process-tree kill on timeout (taskkill /T /F or process group); overall `deadline_sec`; minimal allowlisted child environment plus explicit `extra_env`; artifact paths contained under the run directory without symlinks/junctions; optional `report` dict with truncation flags.
- `tools/vst/slice.py` (rewritten): new keys (worker, supervisor, operator, event; distinct, >= 32 bytes), new manifest fields, lease-based flow (`begin`/`end`), operator-signed waivers, `make_supervisor_receipt`. Four new scenarios: `real_run_and_sign` (real runner, tiny allowed command), `retry_exhausted`, `forged_supervisor_receipt`, `manifest_swap`; the original ten keep their names under the new rules.
- `tools/vst/schemas/README.md`: Store, Runner and Slice sections updated. The A-owned "Known limits" first bullet (event tail truncation not detectable) is now partly stale because of the keyed anchor; it was not edited here.

## Why
Four independent S1 reviewers found: lease rows overwritten (lost history), no retry cap enforcement, WORKER_LOST written for leases that had written receipts, unsigned/unchecked appends (signature, manifest, task link, lease validity), supervisor and worker paths not isolated, a loose transaction helper, no schema versioning, forgeable event chain, runner with unbounded output, orphaned child processes, inherited secrets in the child environment, uncontained artifact paths and commands not tied to the manifest. See `core/DECISION_LOG.md` (2026-10-24, "S1 specialist review") and change record 0015.

## Affected contracts and paths
Breaking Python API: `Store(path, clock, *, event_key)`; `acquire_lease(..., *, supervisor_key)`; `append_receipt(receipt, story_id, key)`; `supervisor_reap_and_mark(supervisor_key, runner_id)` (no `manifest_lookup`); `mark_budget_exceeded(task_id, supervisor_key, runner_id)`; `record_event` kinds limited to `NOTE`/`OPERATOR_ACTION`; new required `register_task` before any lease; `run_and_sign(manifest=..., ...)` (no `task_id`, `role_sha256`; optional `timeout_sec`); `SliceFixture` gains keyword keys. Database layout changed (user_version 2): existing databases are refused, not migrated. Paths: `tools/vst/store.py`, `runner.py`, `slice.py`, `schemas/README.md`. Tests under `tests/vst` that use these APIs need updating (test agents).

## Verification state
Code changed only. Tests were NOT run or rerun by design; nothing was imported or executed (no Python, no sqlite). Not independently reviewed.
