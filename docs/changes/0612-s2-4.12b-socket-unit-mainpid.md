# S2-4.12b — Handle systemd socket properties in root probe helper

## Result

Fixed a runtime blocker in the exact S2-4.12b host-capture helper. systemd omits `MainPID` for
socket units, so requiring it from every unit caused `_assert_dependents_inactive()` to reject the
valid inactive `vst-dispatch-owner.socket` before the one-use runtime claim. The helper now requires
`MainPID` for non-socket units and keeps the exact common-property set mandatory for socket units.
The socket must still be `loaded` and `inactive`; duplicate, missing, malformed, or extra properties
still fail closed.
